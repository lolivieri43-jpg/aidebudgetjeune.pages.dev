# AideBudgetJeune v2

Site statique prêt pour Cloudflare Pages.

## Contenu
- 1 page d’accueil
- 62 pages villes SEO
- 1 simulateur budget en JavaScript
- 1 fichier CSS
- 1 fichier JS
- robots.txt
- sitemap.xml complet
- pages mentions légales et confidentialité

## Mise en ligne simple
1. Décompresser le ZIP.
2. Aller sur Cloudflare > Workers & Pages > Create > Pages > Direct Upload.
3. Nom du projet : aidebudgetjeune.
4. Glisser-déposer tout le contenu du dossier.
5. Déployer.

## À modifier après déploiement
Remplacer partout `https://aidebudgetjeune.pages.dev` par l’URL réelle si Cloudflare donne un autre nom.
Fichiers concernés :
- index.html
- robots.txt
- sitemap.xml
- toutes les pages dans /villes

## Publicité
Les emplacements pubs sont présents mais vides. Attendre la validation Google AdSense avant de coller les scripts.
